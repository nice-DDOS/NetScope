Project capabilities

IP Analyzer

IPv4/IPv6 validation and address classification.

DNS Resolution

Hostname lookup using Python sockets.

TCP Laboratory

Local echo server, client and loopback port checks.

Responsive GUI

Tkinter, background threads and safe queue updates.

Activity History

SQLite storage and CSV report export.

HTTPS Metadata

Optional approximate public IP network information.

Run the desktop application

Download the repository, extract it and open its folder. Python 3.10+ with Tkinter is required.

python main.py
