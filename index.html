Overview

Network programming laboratory project built with Python, socket and Tkinter.

IP and DNS analysis run in your browser. TCP is a simulation; Python provides real TCP sockets and SQLite.

IP intelligence

Public IP details include approximate country, region, ISP and ASN. With consent, GeoJS or ipapi.co receives the public address. Private and local addresses are analyzed offline. IP location is a network estimate, not a person's location.

Help

Run desktop app

Download and extract the source files, install Python 3.10+ with Tkinter, then open a terminal in the extracted folder.

python main.py

On Linux, use python3 main.py. The Windows 7 appearance is a visual style, not a guarantee of compatibility with Windows 7 itself.
